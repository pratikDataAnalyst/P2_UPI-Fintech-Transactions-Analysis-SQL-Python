# 📊 UPI & Fintech Transactions Analysis

## 📌 Project Overview

This project analyzes UPI (Unified Payments Interface) transaction data to understand user behavior, transaction trends, fraud patterns, and overall system performance. The analysis is performed using **Python (EDA & Visualization)** and **SQL (MySQL)**.

---

## 🎯 Objectives

* Analyze transaction success and failure rates
* Identify peak transaction hours and usage patterns
* Understand bank-wise and state-wise transaction distribution
* Detect fraud trends and calculate fraud rate
* Explore customer behavior based on device and transaction amount

---

## 🛠️ Tools & Technologies

* **Python** (Pandas, NumPy, Matplotlib, Seaborn)
* **SQL (MySQL Workbench)**
* **Jupyter Notebook**

---

## 📂 Dataset

* Source: Kaggle
* Size: ~250,000 records (used ~88,000 records for analysis)
* Features include transaction details, user demographics, device type, fraud flag, etc.

---

## 🔍 Key Analysis Performed

### 📊 Exploratory Data Analysis (EDA)

* Transaction Status Distribution
* Hour-wise Transaction Analysis
* Weekend vs Weekday Trends
* Device-wise Transactions
* Bank-wise Transaction Distribution
* Transaction Amount Distribution

---

### 🧠 SQL Analysis

* Total Transactions & Total Amount
* Success vs Failure Rate
* Top Banks by Transactions & Amount
* Fraud Rate Calculation
* Fraud Rate by State
* Peak Transaction Hours
* High-value Transactions
